# אֵבֶל קָטָן

אֲנַחְנוּ מִתְנַהֲלִים בְּתוֹךְ אֵבֶל קְטַנְטַן\
פְּרָטִי, כִּמְעַט נִסְתָּר, פְּרֵדָה מִכָּאן\
כָּל אֶחָד לְעַצְמוֹ אֹסֶף רְגָעִים\
נִזְכַּר בְּשֶׁלּוֹ, זָרוּת לְעִתִּים\
\
רַק כָּל עֶרֶב לְאַט מְגַלִּים\
שֶׁהָיִינוּ פֹּה יַחַד, בְּעֶצֶם, שָׁנִים\
\
זוֹכֶרֶת, אָז, קָנִית פֹּה דִּירָה\
מָצָאנוּ חֲבִילָה שֶׁל נֵרוֹת בַּמְּגֵרָה\
פִּתְאוֹם, הָאוֹר הָיָה גָּדוֹל\
עָלֵינוּ לְמַעְלָה, מִשָּׁם רַק לִפֹּל\
\
אֵיךְ הָרְחוֹב אָז גַּעַשׁ, רָגַשׁ\
אוֹטוֹבּוּסִים, מְהוּמָה\
הַתְּרִיסִים מְלֻכְלָכִים\
שִׁפּוּצִים בְּהַקָּפָה\
\
בָּאִטְלִיז מִמּוּל קָנִינוּ שְׁכֵנוּת\
עַד שֶׁיָּרוּ בּוֹ שׁוּב\
נִהְיֵינוּ שְׁקֵטִים, קְרוֹבִים לַקִּיר \
בַּבְּקָרִים עוֹד סִבּוּב\
\
אָז בָּאָה הָרַכֶּבֶת הַקַּלָּה\
וְיָצָאנוּ אֶל הָעִיר\
שְׂעָרְךָ, הָפַךְ בָּהִיר\
אוֹתוֹ קָפֶה, אוֹתוֹ מְחִיר\
\
בַּבֹּקֶר לָעֲבוֹדָה\
חַיִּים מֵאֲרוּחָה לַאֲרוּחָה\
הַכֹּל נִהְיָה מָהִיר\
קָנִינוּ כַּרְטִיסִים, שִׁלַּמְנוּ כָּל מְחִיר\
\
וְעַכְשָׁו אַתְּ סוֹפֶרֶת אֶת הַדַּקּוֹת\
כָּל יוֹם בַּיָּם, קוֹנֶה מַתָּנוֹת\
\
וַאֲנִי כּוֹתֵב שִׁירִים בַּמִּטְבָּח\
אוּלַי הַיּוֹם כְּבָר לֹא נִבְרַח\
\
טִפּוֹת טִפּוֹת טִפּוֹת בַּיָּם\
טִפּוֹת טִפּוֹת טִפּוֹת מִפֹּה וָשָׁם\
טִפּוֹת טִפּוֹת שֶׁל דָּם\
טִפּוֹת טִפּוֹת טִפּוֹת בַּיָּם\
\
וְעַכְשָׁו הָאֶצְבָּעוֹת\
הֵן עֲיֵפוֹת וְכוֹאֲבוֹת\
הָעֵינַיִם עֲצוּמוֹת\
אֶת חֲלוֹם מְבַקְּשׁוֹת לִרְאוֹת
